# ePlus AI Toolkit v1.0.1

[Documentation home](../README.md) · [Project overview](../../README.md)

Maintenance, safety, documentation and reliability update since the **1.0.0** source release.

## Highlights

- **Safer Google Play diagnostics:** remove temporary copies of the Play Store database after purchase-token lookups, including failed operations ([#20](https://github.com/hoangsvit/google-ai/pull/20)).
- **More reliable checkout review:** reject stale, ambiguous or wrong-account reports rather than treating them as verified results; separate per-account report files by a normalized full-account hash ([#22](https://github.com/hoangsvit/google-ai/pull/22), [#26](https://github.com/hoangsvit/google-ai/pull/26), [#29](https://github.com/hoangsvit/google-ai/pull/29)).
- **Improved interaction safety:** manual Android confirmation now fails closed on timeout/EOF; no fabricated billing address is entered, special characters in ADB text are quoted, and two-factor codes are not written to logs ([#27](https://github.com/hoangsvit/google-ai/pull/27), [#28](https://github.com/hoangsvit/google-ai/pull/28)).
- **Clearer TUI state:** reset device/account status and technical output between runs ([#25](https://github.com/hoangsvit/google-ai/pull/25)).
- **Better test coverage:** Windows Unicode regression coverage and updated maintenance documentation/tests ([#21](https://github.com/hoangsvit/google-ai/pull/21), [#31](https://github.com/hoangsvit/google-ai/pull/31)).
- **User guides:** 7-language README navigation, official MuMu setup instructions, installation Wiki, a clear disclaimer, the possible temporary card authorization hold, and release-source fallback ([#23](https://github.com/hoangsvit/google-ai/pull/23), [#24](https://github.com/hoangsvit/google-ai/pull/24), [#30](https://github.com/hoangsvit/google-ai/pull/30)).

## Download and install

Download **Source code (zip)** from [GitHub Releases](https://github.com/hoangsvit/google-ai/releases), extract it into a new folder, install [MuMuPlayer separately](https://www.mumuplayer.com/download/) and follow the [Install Wiki](https://github.com/hoangsvit/google-ai/wiki/Install). From PowerShell in the extracted folder:

    .\run-all.ps1

To run the offer-listing check directly:

    .\run-all.ps1 -Step 1

**The source ZIP is not a prebuilt Windows .exe/installer.** The toolkit still needs Python, PowerShell, a suitable rooted Android emulator, ADB and compatible Frida. The source ZIP contains the repo files but does not bundle MuMuPlayer.

## Testing and limitations

- The Linux Static checks workflow includes offline Python, PowerShell and JavaScript regression tests.
- A separate **Windows release smoke** workflow validates Python/TUI/PowerShell tests and runs the help commands from an extracted source ZIP on a Windows GitHub runner without connecting to Google Play.
- Actual functionality on **real Windows + MuMu + rooted Android hardware** is not verified by CI; maintainers must perform the manual Step 0–1 [Windows smoke test](https://github.com/hoangsvit/google-ai/blob/main/docs/WINDOWS-SMOKE-TEST.md) before claiming hardware compatibility.
- No actual Google Play subscriptions, checkout, card verification or multi-month extensions have been validated by CI.
- **Steps 2–5 can initiate real charges.** An offer listing, a displayed $0 charge or a local checkout-submission status is not evidence of eligibility or successful activation. Check subscription terms and renewal directly in Google Play. See [Disclaimer](https://github.com/hoangsvit/google-ai/blob/main/DISCLAIMER.md).

## Upgrade guidance

If you use a prior source release, **extract this one into a different folder** and compare its behavior. Do not copy saved credentials, tokens, reports or unredacted logs between folders. A previous release may lack later security and reliability fixes.
