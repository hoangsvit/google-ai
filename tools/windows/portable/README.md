# Windows Portable Diagnostics — experimental

This is a standalone, extract-and-run **diagnostics prototype**, not a portable distribution of the full toolkit. It uses Windows PowerShell 5.1 or later; Python, Git and Frida are not required for the host inspection.

## Run

1. Extract the CI artifact into a local directory you trust.
2. Inspect the scripts, then double-click `Diagnose.bat`.
3. Review the PowerShell, Python-command and ADB-discovery results.

The launcher respects the machine's PowerShell execution policy. If policy blocks the script, ask the system administrator for an approved way to run it. It does not modify policy or require administrator access.

The default inspection does not execute any discovered Python or ADB executable. A detected executable is not evidence that it works or that it is genuine. Windows Store Python aliases may be detected.

For an optional device-count check, obtain Android SDK Platform-Tools from the [official Android website](https://developer.android.com/tools/releases/platform-tools). Review the executable's provenance before running it. From the extracted folder in an approved PowerShell session, use:

```powershell
.\diagnose.ps1 -ProbeDevices -AdbPath 'C:\Android\platform-tools\adb.exe'
```

This explicitly runs only `adb devices`; it may start the local ADB server or request device authorization. It prints counts, never serials, and does not save output. It never installs software, changes emulator settings, reads accounts, instruments billing, or starts checkout.

## Scope and distribution

The artifact contains only the diagnostics scripts, this README and a separate SHA-256 checksum generated by CI. No third-party executable from the reference ZIP is copied, and no Python runtime or full application is bundled. The existing repository entrypoints and payment logic remain unchanged. The prototype has not been validated on a real Windows/MuMu installation.

The reference ZIP inspired the double-click entrypoint and folder layout, not the code or binaries.
